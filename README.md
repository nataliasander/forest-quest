#  Forest Quest

Forest Quest is an interactive, choice-based adventure game built in Python using the pygame library. The player navigates through a mysterious forest by making decisions that affect the storyline and lead to different outcomes.



## Features

- Interactive story with multiple branching paths  
- Multiple endings (good, bad, and alternative)  
- Player decision system (choices affect progression)  
- Animated environment (fireflies, fog, glow effects)  
- Scene-specific graphics created using code  
- Restart system after reaching an ending  



## How the Game Works

The game is structured around scenes and choices:

- Each scene presents story text and multiple choices  
- Each choice leads to a different scene  
- The player progresses through the story based on decisions  
- Different choices result in different endings  



## Requirements

Before running the game, make sure you have:

- Python 3 installed  
- pygame installed  

To install pygame, run:

python3 -m pip install pygame



# How to Play
> Start the game from the start screen
> Read the story displayed on screen
> Click one of the available choices
> Continue making decisions to progress
> Reach different endings depending on your choices
> Restart the game to explore different paths
